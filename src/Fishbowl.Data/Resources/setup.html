WELCOME

Pick at least one sign-in method to get started.

Google sign-in — optional (needs internet)

Use Google OAuth for sign-in. Skip this section if you're running on a LAN without internet — set up a local account below instead.

Local admin account — optional (works offline)

Create a username + password admin. Works with no internet, and can register new local users later. Pick a strong password — there's no email reset flow.

Automatic TLS (Let's Encrypt) — optional

Fishbowl can issue and renew its own certificate. Requires a public domain pointing at this server and inbound ports 80 + 443. Takes effect after a restart.

Discord bot — optional

Connect a Discord bot so you can capture notes, search, and receive reminders from a DM. Create a bot at the Discord Developer Portal, enable User Install on the Installation tab, and paste the token below. Takes effect after a restart.
